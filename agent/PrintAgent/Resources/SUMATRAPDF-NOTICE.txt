SumatraPDF
==========

This directory contains a redistributed copy of SumatraPDF, a free and
open-source PDF reader for Windows. PrintAgent invokes SumatraPDF as a
separate subprocess (silent print mode) to render and print PDF documents.

  Version embedded:    3.6.1

repo root). PrintAgent communicates with SumatraPDF only via process
invocation with command-line arguments, so the two programs are an
